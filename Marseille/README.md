# Signature Marseille — Christelle EGRON

[Ouvrir le fichier HTML](Signature-Christelle-Egron.html)

La version Marseille reprend la signature validée de 450 pixels de large, alignée à gauche, avec les mêmes images, liens, typographies et animation.

Deux lignes centrées sont ajoutées sous le GIF :

**Déléguée nationale UMICC Sud**  
Marseille-Vieux Port

La signature complète mesure 450 × 216 pixels. Tous ses fichiers sont regroupés dans ce dossier ; le HTML utilise leurs URL HTTPS absolues dans Marseille.

Pour l’utiliser dans Gmail, ouvrir le fichier HTML téléchargé dans un navigateur, puis copier le rendu et remplacer la signature précédemment enregistrée. Le GIF recadré utilise ses dimensions réelles d’affichage, sans masquage HTML.
