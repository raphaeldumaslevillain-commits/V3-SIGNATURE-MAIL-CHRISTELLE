## GIF et collage dans Gmail

Le HTML utilise **`impact-makers-gmail.gif`**, recadré dans le fichier lui-même à 840 × 92 pixels et affiché à **420 × 46 pixels** entre les traits. Aucun masquage HTML, débordement ni marge négative n’est nécessaire.

Les 64 images et leurs durées ont été comparées à la zone correspondante du GIF source : pixels identiques, boucle de 13,7 secondes, même curseur et mêmes mouvements. Le fichier original `impact-makers.gif` est conservé.

Après cette correction, remplacer la signature déjà collée dans Gmail par une nouvelle copie du rendu HTML actualisé. Une signature déjà enregistrée conserve son ancien code.
